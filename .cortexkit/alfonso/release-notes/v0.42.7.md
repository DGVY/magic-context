## Fixes

- **Shadow embeddings are discarded when their registration is retired mid-embed (#470, Qiiks).** A provider round-trip can take seconds (tens on a cold Synapse load); if the shadow registration was unregistered or replaced in that window, the returned vectors were still written under the retired lane and read as valid backfill on a later re-arm. The live registration generation is re-checked after the await in all three scopes and the write is refused with a named reason; a retired item's outcome no longer feeds the stall detector for its replacement.

## Performance

- **Defer passes on large sessions are cheaper.** The post-transform phase no longer re-measures an unchanged tail on every pass (38 → 6 ms on a 2,250-message session), and the rust-mode adapter no longer re-parses the replay document when its source text is byte-unchanged (apply 13 → 2.5 ms). Served bytes are identical.

## Tests

- Host-behavior e2e scenarios are written once and run per host from the mode manifest (OpenCode 1, OpenCode 2, Pi, OMP) through one harness contract; the manifest refuses a host missing from a scenario without a stated reason.
- Several wall-clock test budgets that read the CI runner instead of the code (#472, Qiiks) now assert size ratios or same-process comparisons; absolute caps run only under `MC_PERF_GATE`.
- The release script commits a `Cargo.lock` that drifted during the gates on its own, builds the hermetic daemon from the sibling's committed HEAD, installs OpenCode through a loud pinned installer, and falls back to the installer's path when `opencode` is not on the ambient PATH.
